# StepUp Arabic — קורס ערבית אופליין

קורס דיגיטלי בעברית ללימוד ערבית מאפס, עם תוכנת Windows ואפליקציית Android עצמאיות. המבנה והעיצוב מבוססים על StepUp English.

## מה יש בגרסה הנוכחית
- 57 יחידות לימוד: 24 בערבית מדוברת פלסטינית ו-33 בערבית ספרותית תקנית (MSA). המסלול הספרותי מתחיל בארבע יחידות אלפבית, חיבור אותיות, ניקוד וקריאה ראשונה.
- 404 פריטי לימוד ואוצר מילים בסיסיים, עם כתיב ערבי, תרגום לעברית ותעתיק עזר. לכל מילה יש קובץ שמע משלה, ולכל אחת מ-28 האותיות יש השמעת שם.
- כל 57 היחידות כוללות הסבר קצר ודוגמת משפט מוקראת.
- האלפבית הערבי: 28 אותיות, עם צורות נפרדות, תחיליות, אמצעיות וסופיות.
- לכל שיעור מאגר שאלות שנוצר מתוכן השיעור, כולל שאלות הבנת משפטים: מערבית לעברית ומהעברית לערבית. השאלות והתשובות מעורבבות; לכל שאלה ארבע אפשרויות ומשוב.
- מבחן שיעור, מבחן מסכם לחומר שנלמד, שמירת ציונים ורשימת טעויות לתרגול.
- חזרה חכמה במרווחי זמן, מילון ערבי–עברי עם חיפוש, רשימת מועדפים ויעד לימוד יומי.
- מעבדת שמיעה נפרדת עם סינון לפי מסלול, הצגת התרגום רק לאחר האזנה ותרגול משפטים מוקראים.
- מצב כהה, שליטה במהירות השמע, שינוי גודל הכתב הערבי, לוח הישגים ותרשים פעילות שבועי.
- לכל משפט דוגמה נוצר קובץ WAV מקומי, והוא זמין להאזנה ולתרגול הבנת הנשמע. 20 תוצאות המבחן המסכם האחרונות נשמרות ומופיעות במסך ההתקדמות.
- חמש הקלטות אנושיות קצרות בערבית כללית/ספרותית ממאגר Nahw, ברישיון CC BY 4.0. בנוסף, קובצי שמע סינתטיים שנוצרים מראש: קול פלסטיני ייעודי למילים במסלול המדובר וקול MSA למילים במסלול הספרותי ולשמות האותיות.
- מדריך מובנה על ערבית קלאסית, MSA, ערבית מדוברת והניבים המרכזיים, עם עזרה בבחירת מסלול.
- התקדמות, ציונים, טעויות ובחירת מסלול נשמרים אוטומטית בכל שינוי. ב-Windows השמירה נשמרת בפרופיל WebView2 קבוע תחת %LOCALAPPDATA%/StepUpArabic/WebView2; באנדרואיד נשמר גם קובץ פנימי אטומי בשם stepuparabic-progress.json. אפשר לייצא ולשחזר גיבוי JSON.

## שמע ותצוגת ערבית
- לכל מילה ולכל שם אות מצורף קובץ WAV נפרד, הנכלל בתוך קובצי ההתקנה. במסלול הפלסטיני נעשה שימוש בקול סינתטי ייעודי של Sofelia; במסלול הספרותי ובשמות האותיות נעשה שימוש בקול MSA של Nabra.
- חמש ההקלטות האנושיות של Nahw נשארות מסומנות בנפרד כערבית כללית/ספרותית, ולא כמבטא פלסטיני.
- גופן Noto Sans Arabic ורישיון OFL שלו נארזים בתוך התוכנה והאפליקציה. אין צורך להתקין תמיכה בשפה הערבית ב-Windows.
- מודלי הדיבור מופעלים רק בזמן הבנייה. במחשב ובטלפון נשמרים קובצי WAV מוכנים, ולכן אין צורך באינטרנט, בהתקנת Python או בשירות דיבור חיצוני בזמן הלימוד.
- התוכן הוא גרסת לימוד ראשונה ונדרש עדיין מעבר הגהה של דובר ערבית ילידי/מורה, במיוחד על התעתיק, הניואנסים המדוברים והדוגמאות.
- אין סנכרון אוטומטי בין מכשירים; מעבר בין המחשב לטלפון נעשה באמצעות גיבוי ושחזור.

## הגהה ותחזוקת תוכן

אפשר לייצא את כל השיעורים, המילים ומשפטי הדוגמה לקובץ JSON להגהה, בלי לערוך את קוד התוכנה:

```bash
python scripts/content_review.py export --output content-review.json
```

לאחר שמורה או מגיה ערכו את הקובץ, יש לסמן כל רשומה שאושרה בשדה `review_status` בערך `approved`, ולמלא את פרטי הבודק ותאריך הבדיקה. החזרת התיקונים המאושרים לקובץ HTML נעשית כך:

```bash
python scripts/content_review.py apply --input content-review.json --output index.html
```

הכלי דוחה קובץ הגהה המבוסס על גרסת תוכן ישנה, מזהים כפולים ושדות חובה ריקים. הוא אינו מאשר בעצמו נכונות לשונית: הגהה של דובר ערבית ילידי/מורה עדיין נדרשת.

תיעוד הנכסים והרישיונות נמצא ב-`docs/license-audit.md`. בדיקות CI מאמתות התאמה בין המילים, משפטי הדוגמה, מניפסטי השמע והקרדיטים של הקלטות המקור.

## מבנה
- index.html — ממשק ותוכן הלימוד.
- desktop/ — מעטפת Windows באמצעות Go ו-Microsoft WebView2.
- android/ — מעטפת Android באמצעות WebView מקומי. אין הרשאת INTERNET במניפסט.
- .github/workflows/ — בנייה אוטומטית של EXE ו-APK, הורדת קטעי השמע המורשים, אימות ההטמעה ובדיקת פתיחה.
- tests/ — בדיקות לתוכן, לשאלות, לשמירה אוטומטית ולשחזור.
- docs/ — אפיון, מפת יחידות ותיעוד רישיונות.

## שמע ורישוי
הקלטות Nahw נבחרות לפי תמלול מדויק, מועתקות ללא עריכה, ונארזות בשתי ההתקנות. נוסף עליהן, תהליך הבנייה מייצר קובצי WAV לכל מילות שני המסלולים ולכל שמות האותיות באמצעות Sofelia (פלסטינית) ו-Nabra (MSA). גופן Noto Sans Arabic נארז יחד עם רישיון OFL. הקרדיטים, הרישיונות ומניפסטים של כל קובצי השמע מצורפים תחת audio/ATTRIBUTION.md ו-audio/generated/. פירוט המקורות והבדיקה של מאגרי הדיבור הפלסטיני נמצא ב-docs/audio-sources.md.

## בנייה והורדה
- Windows: GitHub Actions → Build StepUp Arabic desktop app.
- Android: GitHub Actions → Build StepUp Arabic Android APK.
- קובצי ההתקנה זמינים ב-GitHub Releases; אימות הרצת Android באמולטור מתבצע בנפרד.

היישומים נועדו לפעול ללא אינטרנט לאחר ההתקנה. האינטרנט נדרש רק בתהליך הבנייה לצורך הורדת מודלי יצירת השמע וקטעי המקור המורשים.


## שמירת נתונים ועדכון גרסאות

- ב-Windows, פרופיל WebView2 וההתקדמות נשמרים תחת `%LOCALAPPDATA%/StepUpArabic`; החלפת קובץ ה-EXE אינה אמורה למחוק אותם.
- ב-Android, קובץ ההתקדמות נשמר בתיקייה הפרטית של האפליקציה. עדכון APK שומר את הנתונים כאשר מזהה האפליקציה ומפתח החתימה נשארים זהים.
- APK שנבנה ב-Pull Request מיועד לבדיקות ומשתמש בחתימת Debug. פרסום APK מענף `main` דורש מפתח חתימה קבוע דרך GitHub Actions Secrets; ללא ארבעת הסודות הבנייה נעצרת ולא מתפרסם APK בעל חתימה מתחלפת.
- לפני התקנה ראשונה של גרסה חתומה במפתח חדש במקום APK ישן, מומלץ לייצא גיבוי JSON ולשמור אותו מחוץ לאפליקציה. הסרת התקנה באנדרואיד מוחקת את הנתונים המקומיים; לאחר מכן ניתן לשחזר את קובץ הגיבוי.

### הגדרת מפתח חתימה קבוע לאנדרואיד

יש ליצור פעם אחת מפתח מקומי, לשמור אותו במקום בטוח ולא להעלות אותו למאגר:

```powershell
keytool -genkeypair -v -keystore stepup-arabic-release.jks -storetype JKS -keyalg RSA -keysize 2048 -validity 10000 -alias stepuparabic
```

ב-GitHub: Settings → Secrets and variables → Actions, יש להגדיר את הסודות הבאים:
- `ANDROID_KEYSTORE_BASE64` — תוכן קובץ ה-JKS בקידוד Base64. ב-PowerShell אפשר להפיקו כך: `[Convert]::ToBase64String([IO.File]::ReadAllBytes(".\stepup-arabic-release.jks"))`.
- `ANDROID_KEYSTORE_PASSWORD` — סיסמת מאגר המפתחות.
- `ANDROID_KEY_ALIAS` — שם המפתח; בפקודה למעלה: `stepuparabic`.
- `ANDROID_KEY_PASSWORD` — סיסמת המפתח.

יש לשמור גיבוי מאובטח של קובץ ה-JKS והסיסמאות. אובדן מפתח החתימה ימנע עדכון APK שהותקן עם המפתח הזה.

## התקנה
- **Windows:** הורידו את StepUp-Arabic.exe והפעילו. נדרש Microsoft Edge WebView2 Runtime; הוא כלול ב-Windows 11 וברוב מחשבי Windows 10. אם הוא חסר, יש להתקין אותו פעם אחת. קובץ ה-EXE אינו חתום דיגיטלית, ולכן Windows עשוי להציג אזהרת SmartScreen.
- **Android:** הורידו את StepUp-Arabic-v2.0.0.apk ופתחו אותו להתקנה ידנית. נדרש Android 6.0 ומעלה. APK של בדיקות PR חתום בחתימת debug; APK רשמי מענף `main` נחתם במפתח הקבוע שהוגדר ב-GitHub Secrets. אין מדובר בפרסום דרך Google Play.
