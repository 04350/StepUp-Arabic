# StepUp Arabic — קורס ערבית אופליין

קורס דיגיטלי בעברית ללימוד ערבית מאפס, עם תוכנת Windows ואפליקציית Android עצמאיות. המבנה והעיצוב מבוססים על StepUp English.

## מה יש בגרסה הנוכחית
- 49 יחידות לימוד: 20 בערבית מדוברת פלסטינית ו-29 בערבית ספרותית תקנית (MSA). המסלול הספרותי מתחיל בארבע יחידות אלפבית, חיבור אותיות, ניקוד וקריאה ראשונה.
- 343 פריטי לימוד ואוצר מילים בסיסיים, עם כתיב ערבי, תרגום לעברית ותעתיק עזר, ובנוסף 5 משפטי האזנה מוקלטים.
- כל 49 היחידות כוללות הסבר קצר ודוגמת משפט.
- האלפבית הערבי: 28 אותיות, עם צורות נפרדות, תחיליות, אמצעיות וסופיות.
- לכל שיעור מאגר שאלות שנוצר מתוכן השיעור: מערבית לעברית ומהעברית לערבית. השאלות והתשובות מעורבבות; לכל שאלה ארבע אפשרויות ומשוב.
- מבחן שיעור, מבחן מסכם לחומר שנלמד, שמירת ציונים ורשימת טעויות לתרגול.
- חמש הקלטות אנושיות קצרות בערבית כללית/ספרותית ממאגר Nahw, ברישיון CC BY 4.0. בשיעורים המתאימים קיימות גם שאלות הבנת הנשמע.
- התקדמות, ציונים והגדרות נשמרים מקומית; ייצוא ושחזור גיבוי בקובץ JSON.

## מה עדיין מוגבל
- חמש ההקלטות הן בערבית כללית/ספרותית, ולא במבטא פלסטיני. אין כרגע הקלטות מאושרות להפצה למסלול הפלסטיני, ולכן התוכנה לא תציג קול אחר כאילו הוא פלסטיני.
- מודל Nabra נבדק כאפשרות עתידית ליצירת קול MSA, אבל אינו משולב כרגע בתוך האפליקציה.
- התוכן הוא גרסת לימוד ראשונה ונדרש עדיין מעבר הגהה של דובר ערבית ילידי/מורה, במיוחד על התעתיק, הניואנסים המדוברים והדוגמאות.
- אין סנכרון אוטומטי בין מכשירים; מעבר בין המחשב לטלפון נעשה באמצעות גיבוי ושחזור.

## מבנה
- index.html — ממשק ותוכן הלימוד.
- desktop/ — מעטפת Windows באמצעות Go ו-Microsoft WebView2.
- android/ — מעטפת Android באמצעות WebView מקומי. אין הרשאת INTERNET במניפסט.
- .github/workflows/ — בנייה אוטומטית של EXE ו-APK, הורדת קטעי השמע המורשים, אימות ההטמעה ובדיקת פתיחה.
- tests/ — בדיקות לתוכן, לשאלות ולתחביר JavaScript.
- docs/ — אפיון, מפת יחידות ותיעוד רישיונות.

## שמע ורישוי
הקלטות Nahw נבחרות לפי תמלול מדויק, מועתקות ללא עריכה, נארזות בשתי ההתקנות ומוצגות רק במסלול הספרותי. הקרדיט והרישיון מצורפים תחת audio/ATTRIBUTION.md, וקובץ manifest עם התמלול ומקורו נארז גם הוא בכל התקנה. פירוט המקורות והבדיקה של מאגרי הדיבור הפלסטיני נמצא ב-docs/audio-sources.md.

## בנייה והורדה
- Windows: GitHub Actions → Build StepUp Arabic desktop app.
- Android: GitHub Actions → Build StepUp Arabic Android APK.
- קובצי ההתקנה זמינים ב-GitHub Releases; אימות הרצת Android באמולטור מתבצע בנפרד.

היישומים נועדו לפעול ללא אינטרנט לאחר ההתקנה. האינטרנט נדרש רק בתהליך הבנייה לצורך הורדת קטעי המקור המורשים.


## התקנה
- **Windows:** הורידו את StepUp-Arabic.exe והפעילו. נדרש Microsoft Edge WebView2 Runtime; הוא כלול ב-Windows 11 וברוב מחשבי Windows 10. אם הוא חסר, יש להתקין אותו פעם אחת. קובץ ה-EXE אינו חתום דיגיטלית, ולכן Windows עשוי להציג אזהרת SmartScreen.
- **Android:** הורידו את StepUp-Arabic-v0.1.0.apk ופתחו אותו להתקנה ידנית. נדרש Android 6.0 ומעלה. ה-APK חתום בחתימת debug לצורך התקנה ידנית, ולא בחתימת הפצה של Google Play.

הורדות רשמיות: https://github.com/04350/StepUp-Arabic/releases/tag/v0.1.0
